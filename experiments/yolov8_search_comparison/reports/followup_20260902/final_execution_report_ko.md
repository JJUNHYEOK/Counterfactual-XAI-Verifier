# KCI 추가 실험 최종 실행 보고

## 1. 가중치 탐색

저장소, 지정 사용자 폴더, 인접 프로젝트 및 Git 이력을 검색했다. 기존 시뮬레이션 학습 가중치는 없었다. 외부 후보 `Downloads/best.pt`는 정상 로드됐지만 YOLO11n/VisDrone 5클래스 모델이며 수정 GT 기준 mAP@0.5 0.480903(MARGINAL)으로 채택하지 않았다.

## 2. GT 수정과 후보 재평가

기존 핀홀 투영 GT가 3차원 렌더 픽셀과 맞지 않는 문제가 확인됐다. 객체 크기를 변경하지 않고 렌더 인스턴스 색상 패스에서 가시 픽셀 박스를 생성하도록 수정했다. 일반 YOLOv8s는 0.000000에서 0.177966으로 회복했으나 FAIL, 외부 후보는 0.480903으로 MARGINAL이어서 맞춤 학습이 필요했다.

## 3. 학습

최종 variant 0 시험 영상을 제외하고 6개 train 시나리오(366장), 2개 validation 시나리오(122장)를 구성했다. 시나리오별 UAV 위치·고도, 객체 배치, 보행 위상을 결정론적으로 달리했고 인접 프레임은 분할을 넘지 않았다. 사람 라벨 317개, 차량 라벨 351개다. train/val 시나리오 교집합, 이미지 SHA-256 교집합, 최종 시험 포함 여부가 모두 0이었다.

24장 1 epoch smoke 학습 후 YOLOv8s 전체 학습을 수행했다. 요청 50 epoch, patience 12, batch 4, imgsz 640, SGD, seed 42였고 validation 개선 정체로 13 epoch에서 조기 종료됐다. 선택한 `best.pt`의 SHA-256은 `C5C549611CBE39EBCDB051863EE80F92AE0072266FEEB71A21CC7AABEBF57ECA`다.

## 4. 독립 기준 조건 검증

학습·모델 선택에 사용하지 않은 181프레임에서 mAP@0.5 0.975043(PASS), 사람 AP 0.966102, 차량 AP 0.983984를 얻었다. 사람 TP/FP/FN은 114/0/4, 차량은 129/10/2다. micro precision 0.960474, recall 0.975904, 최대 IoU 0.987195, 탐지별 최대 IoU 평균 0.911944다.

## 5. 경계 탐색 비교

두 방법 모두 최초 FAIL은 4회였다. 대칭 탐색은 10회 모두 신규 평가했고 최종 비실패/실패 mAP는 0.266626/0.237385, Gap_mAP 0.029241, Gap_env 0.010948이었다. 비대칭 탐색은 논리적 10회 중 신규 5회·공유 캐시 5회였고 최종 비실패/실패 mAP는 0.282734/0.075463, Gap_mAP 0.207271, Gap_env 0.081277이었다.

이 단일 결정적 시나리오에서는 대칭 탐색의 두 gap이 모두 더 작았다. 따라서 비대칭 탐색이 더 우수하다고 주장할 수 없다. 또한 단일 시나리오 결과로 통계적 유의성이나 실제 항공 영상 일반화를 주장할 수 없다.

## 6. 보존 및 공간 대응

기존 실패 실행은 삭제·덮어쓰기하지 않았다. 디스크 부족 시 이번 작업이 만든 데이터 중복본만 하드링크로 바꿨고, 진단 오버레이는 JPEG로 압축했다. 학습 검사 영상은 JPEG로 보존하되 원본 PNG 해시와 재생성 계획을 남겼다. 최종 선택 `best.pt`는 보존했다. 비선택 smoke 체크포인트와 full `last.pt`는 SHA-256을 기록한 뒤 공간 확보를 위해 제거했다. 커밋·push는 수행하지 않았다.
